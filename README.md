# 🪪 Student ID Card Detection using CNN

A deep learning project that uses a Convolutional Neural Network (CNN) to detect whether a student is wearing an ID card or not.

## 📌 Project Overview

This project classifies student images into two categories:

- 🪪 Wearing ID Card
- ❌ Not Wearing ID Card

The project uses image preprocessing, data augmentation, and a CNN model built with TensorFlow and Keras.

## 🎯 Objective

The main objective is to develop an image classification system that can automatically identify whether a student is wearing an ID card.
